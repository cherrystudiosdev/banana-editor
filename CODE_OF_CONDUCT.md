# Community code of conduct

Treat contributors and users with respect. Give specific, constructive feedback;
discuss technical choices without attacking people. Welcome differing experience,
backgrounds and accessibility needs. Respect privacy and intellectual property.

Harassment, threats, discrimination, sexualized attention, personal attacks,
doxxing and sharing private information without permission are not acceptable.
Do not misuse issue trackers or pull requests for spam or targeted disruption.

Maintainers may edit or remove violating material, limit participation, or block
accounts. They should explain actions where doing so does not expose private
information and should apply the same expectations to themselves.

Once a public repository is established, report community incidents through an
available private maintainer contact on that repository. No dedicated contact
address is currently verified. Do not publish sensitive reports or personal data
in public issues. This policy covers project spaces and representation of the
project in other communities.
