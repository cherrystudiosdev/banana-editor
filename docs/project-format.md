# Banana project format, schema 1

`.banana` files contain UTF-8 JSON. `schemaVersion`, `appVersion`, `id`, `name`, `revision`, `assets`, `sequence`, `linkedGroups`, and `appliedPlanIds` are persisted. Credentials never belong in this model. All fields are runtime validated; unknown fields are rejected. The loader rejects newer/unknown schema versions without modifying the original. There were no released older formats to migrate; future migrations must be explicit pure functions.

The sequence holds a rational `fps: {num, den}`, dimensions, sample rate, ordered tracks and markers. All timeline positions, durations, keyframe offsets, transition durations and marker positions are integer frames. Intervals include the start and exclude the end. Source in-points are seconds in the asset time domain; the source out-point is `sourceIn + duration * fps.den / fps.num`. Frames, seconds and audio samples are never interchangeable. Sample conversion uses integer arithmetic and rounds once. Timecode displays non-drop-frame nominal frame labels; it is not a wall clock for fractional frame rates.

Assets retain probed metadata and their external source path. The desktop persistence layer resolves relative source paths against the saved project's directory. Removing an asset only removes the reference and is rejected while clips still use it. It never deletes source files.

Tracks are ordered bottom to top for visual composition. `V1` is below `V2`. Audio clips require audio tracks; video, image, title and caption clips require video tracks. A video clip can carry its source audio until detached. Visibility affects pictures; mute and solo affect audio. A solo track silences all non-solo tracks' audio. A locked track rejects clip changes and its own edits until unlocked.

Same-track overlap is forbidden except an explicitly modeled `crossDissolve` on an incoming clip whose duration equals its overlap with the preceding clip. Triple overlap is rejected. Adding a dissolve moves the incoming clip earlier using its existing media; it does not fabricate missing handles. The incoming visual alpha rises from zero to one over that overlap, over the opaque outgoing picture. Audio uses opposing linear ramps. Other layers may overlap freely on different tracks.

Effects use sequence pixel offsets from center for x/y, ratios for scale, opacity, volume and crop, degrees for rotation, brightness -1..1, and neutral contrast/saturation 1. Crop fractions must leave a nonempty image. Fades are frame counts. Fade-in is `min(1, localFrame/fadeIn)`; fade-out is `min(1, (duration-localFrame)/fadeOut)`. Both affect picture opacity and audio gain, and overlapping fades use the smaller factor. Keyframes are relative to clip start. Supported properties are x, y, scale, opacity and volume. Values hold outside the first/last keyframe. Between keys, the left key selects linear or hold interpolation. An endpoint key at `duration` is permitted although the clip's end is exclusive.

Splitting a fade preserves the values of every sampled timeline frame by translating its envelope into opacity/volume keyframes on the two pieces. Linear spans remain sparse; nonlinear combinations of an animated property and fade are sampled at integer frames. Exceptionally long nonlinear envelopes that would exceed the 10,000-keyframe project limit are rejected atomically with an explanatory error. Copying both members of a dissolve retains the transition; copying an incoming member alone removes its now-orphaned transition.

Every command batch is applied to a private clone and validated in full before returning. Invalid edits do not partially change a project. Revision increases once per successful transaction, and also increases on undo/redo so stale AI plans cannot become current again accidentally. One drag or accepted AI plan uses one history entry.

Moving, trimming, splitting and deleting a clip include its linked group. Linked changes fail if any affected track is locked. Unlink removes the complete associated group. Normal delete preserves gaps. Ripple delete closes the union of deleted intervals on affected tracks only and moves linked followers by the same amount; conflicting shifts or remaining clips intersecting the removed intervals are rejected. Ripple trim shifts followers on edited tracks, and linked followers elsewhere, by the change in the trimmed clip's end. Other tracks are unaffected. Trimming left while ripple is enabled consequently keeps the original end and does not shift followers unless the end also changes. Markers are absolute sequence positions and do not ripple automatically.

SRT/WebVTT import normalizes timestamps to sequence frames once. Styling markup is converted to plain text. Export uses timeline caption positions. Transcript mapping intersects source-time cues with the visible clip source interval before adding the timeline offset; translation should preserve those cue intervals.
